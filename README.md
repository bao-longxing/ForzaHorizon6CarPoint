## 项目简介

Horizon 6 脚本工具是一款基于计算机视觉与硬件级模拟的《极限竞速：地平线 6》全自动化辅助工具。它通过 **OBS 截图 + PaddleOCR 文字识别 + 驱动级键鼠模拟**，实现游戏中刷蓝图、批量买车、技能加点、删车腾位等重复操作的完全无人值守。

> 核心目标：把地平线6里所有无聊的肝活，变成一键自动完成。

## 功能特性

### 五大核心功能

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 全自动执行 | F5 | 状态机串联比赛→买车→加点→删车，全自动循环 |
| 蓝图脚本 | F9 | 自动反复进入并完成指定蓝图比赛，刷钱刷经验 |
| 从收集簿购买 | F6 | 批量购买指定品牌、型号、数量的车辆 |
| 消耗技能点数 | F7 | 自动为车辆加满技能点数 |
| 从车库移除 | F8 | 批量删除车库中不需要的车辆 |

### 辅助工具

| 功能 | 说明 |
|------|------|
| OBS 集成 | 通过 WebSocket 连接 OBS，实时获取游戏画面截图 |
| OCR 识别 | 基于 PaddleOCR ChineseV3 模型识别游戏内文字 |
| ROI 区域管理 | 18 个预定义屏幕区域，加速 OCR 定位 |
| MousePos 覆盖层 | 实时显示鼠标坐标，方便校准识别区域 |
| 全局热键 | F1-F12 全局键盘钩子，游戏中也能触发 |
| 实时日志 | 四级分类日志（信息/成功/警告/错误）+ 进度条 + 预计耗时 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | .NET 10.0 WPF (Windows) |
| 语言 | C# 13 |
| OCR | Sdcb.PaddleOCR + PaddleOCR ChineseV5 模型 |
| 图像处理 | OpenCvSharp4 |
| 画面采集 | OBS WebSocket (obs-websocket-dotnet) |
| 硬件模拟 | 底层驱动 DLL (device_control.dll) |
| 键盘钩子 | Windows API SetWindowsHookEx |

### 为什么用驱动级模拟而不是 SendInput？

游戏通常有反作弊保护，SendInput / mouse_event 等 Windows API 级别的模拟容易被检测拦截。通过底层驱动 DLL 发送键鼠指令，走的是**硬件驱动层**，兼容性更好、更不易被检测。

## 安装与运行
1.下载Release中的exe
2.下载lghub_installer - 2020.1.31550.0并安装
3.下载OBS并安装，配置好地平线6，游戏窗口采样，打开OBS顶部的工具->WebSocket服务器，打开之后记下IP和Port。

> **必须以管理员权限运行**，否则全局键盘钩子无法工作。程序启动时会自动检测并提示。

## 使用指南

### 初次配置

1. 启动 OBS Studio，在 **工具 → WebSocket 服务器设置** 中开启服务，记下端口号与密码
2. 打开本工具，点击底部 **OBS** 按钮，填入 OBS 的 IP（默认 localhost）、端口和密码
3. OBS 连接成功后，顶部状态栏显示「OBS连接：● 已连接」

### 使用自动化功能

**方式一：全自动一键（推荐）**

1. 填写好左侧配置参数：
   - **蓝图代码** — 你要刷的比赛蓝图分享码
   - **车辆厂商 / 车辆名称** — 要购买的车
   - **购买数量** — 每次批量购买多少辆
   - **单局点数** — 每场比赛获得多少技能点
2. 将游戏画面切换到大地图视角
3. 按 F5，工具自动开始循环：`比赛 → 买车 → 加点 → 删车 → 下一轮`

**方式二：单独执行**

| 操作 | 快捷键 | 场景 |
|------|--------|------|
| 只刷比赛 | F9 | 只想刷钱/经验 |
| 只买车 | F6 | 只想批量买车，不刷比赛 |
| 只加点 | F7 | 车库里有车需要补技能点 |
| 只删车 | F8 | 车库满了，清理空间 |

**停止操作**

按 F11 可以优雅地取消当前正在执行的操作，不会导致游戏卡死。

### 调试工具

| 按钮 | 用途 |
|------|------|
| OCR | 测试 OCR 识别效果，截取当前游戏画面进行文字识别 |
| 买车脚本测试 | 单独测试买车流程，不触发完整自动化 |
| KeyBoard | 测试键盘钩子是否正常工作 |

## 自动化工作流

### AutoManager 状态机

```
                    ┌──────────┐
                    │   Idle   │
                    └────┬─────┘
                         │ F5 启动
                         ▼
                  ┌──────────────┐
                  │   蓝图比赛    │
                  └──────┬───────┘
                         │ 比赛完成
                         ▼
                  ┌──────────────┐
                  │   批量买车    │
                  └──────┬───────┘
                         │ 购买完毕
                         ▼
                  ┌──────────────┐
                  │   技能加点    │
                  └──────┬───────┘
                         │ 加点完成
                         ▼
                  ┌──────────────┐
                  │   删除车辆    │◀── 循环 ──┐
                  └──────┬───────┘           │
                         │                   │
                         ▼                   │
                   熟练度=999？ ── 否 ───────┘
                         │
                        是
                         ▼
                    ✅ 全部完成
```

### 关键技术链路

```
OBS截图 ──▶ OpenCV裁剪ROI区域 ──▶ PaddleOCR识别文字
                                        │
            底层驱动 ◀── 业务逻辑决策 ◀──┘
                │
                ▼
           游戏响应操作
```

每轮循环依次执行 **比赛 → 买车 → 加点 → 删车**，直至所有车辆熟练度达到 999 上限自动停止。
